# MELSSY

Read `AGENTS.md` before changing this repository.

MELSSY is a standalone French, mobile-first cash-on-delivery storefront for Morocco. The running code is a Next.js app in `frontend/` and a FastAPI service in `backend/`; it is not a Shopify theme. Use relative frontend API paths through the Next.js `/api` proxy, validate mobile work at 375px, and do not commit local databases or generated artifacts.
